Lighthouse model used by layers/ports.js for Kannonzaki Lighthouse.

Source: Kenney's Pirate Kit (https://kenney.nl/assets/pirate-kit), via
the glTF-converted mirror at https://github.com/shorepine/kenney
(3d/pirate/). tower-complete-small.glb is a pre-assembled watchtower,
standing in for a lighthouse - no dedicated lighthouse model exists in
either kit checked.

Textures/colormap.png is this kit's own shared texture atlas - a
different file than ship-models/Textures/colormap.png despite the
identical relative path each .glb references, since each Kenney kit
ships its own palette. That's why this lives in a separate folder
rather than reusing ship-models/.
